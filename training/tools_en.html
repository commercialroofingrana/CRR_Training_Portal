Why Tool Safety Matters

Hand and power tools cause thousands of construction injuries each year. At CRR, proper tool use is non-negotiable — the right tool, used the right way, every time.

  • OSHA 29 CFR 1926 Subpart I governs hand and power tool safety
  • Common injuries: lacerations, punctures, amputations, eye injuries, electrical shock
  • Most tool injuries are preventable with proper training and inspection
  • Never use a tool you have not been trained on
👷

Roles & Responsibilities

  • Employees – Inspect tools before use; use tools only for their intended purpose
  • Supervisors – Enforce tool safety; remove defective tools from service
  • Management – Provide appropriate tools and PPE; maintain repair/replacement program
  • All – Report damaged tools immediately; never use improvised tools
🛑

Stop Work Authority

Stop work if you observe unsafe tool use — including by yourself:

  • A damaged tool is a hazard — remove it from service and tag it
  • If a guard is removed or bypassed — stop work and correct it
  • If a tool is being used for the wrong application — stop and find the correct tool
  • Report concerns to your supervisor; you will not face retaliation
🔍

Pre-Use Tool Inspection

Inspect every tool before each use:

Hand Tools
✅ Handles not cracked/loose
✅ No mushroomed heads (chisels)
✅ Edges sharp and undamaged
✅ No tape covering damage
Power Tools
✅ Guards in place
✅ Cord/battery undamaged
✅ Trigger/switch functions
✅ Correct blade/bit for task
🛡️

Guards & Safety Devices

All power tool guards must remain in place during operation:

  • ❌ Never remove, bypass, or defeat a guard for any reason
  • ✅ If a guard is missing or damaged — the tool is out of service until repaired
  • ✅ Blade guards on circular saws protect you from kickback and contact
  • ✅ Disc guards on grinders prevent fragment ejection
  • ✅ Trigger locks and dead-man switches must function correctly
⚡

Electrical Safety for Power Tools

  • Use only double-insulated tools or properly grounded equipment
  • GFCI protection required for all electric tools near moisture
  • Never carry tools by the cord or yank to disconnect
  • Keep cords away from sharp edges, heat, oil, and chemicals
  • Never use electric tools in wet conditions without GFCI protection
  • Extension cords must be rated for the tool's amperage
🦺

PPE for Tool Use

Always wear appropriate PPE when using hand or power tools:

👓
Eye Protection
Always for cutting/grinding
🧤
Gloves
Cut-resistant when handling sharp tools
🦺
Hi-Vis
When working near other trades
🗂️

Recordkeeping

  • Defective tools tagged "Out of Service" and removed from the site
  • All tool-related injuries reported and investigated
  • Tool inspection logs may be required on larger projects
  • Training records for power tool use retained for 3 years
